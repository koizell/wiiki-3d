# Prusa CORE One Review — Tom's Hardware

Última actualización: 7 de diciembre de 2025. Veredicto del editor: Editor's Choice.

## Extractos literales

> ### Tom's Hardware Verdict
> Prusa literally transformed their classic i3 printer into a Core XY machine with
> more speed and all the outstanding quality we expect from an industry leader.
> **The enclosure has a clever design that allows for creative modding, but it oddly
> lacks expected premium features like a built-in camera.**

> #### Reasons to buy
> - Core XY speed
> - High flow CHT Nozzle
> - Perfect first layer
> - Very quiet
> - Fully assembled or DIY kit
> - Can be upgraded from a MK4
>
> #### Reasons to avoid
> - Expensive
> - Chamber heated by bed
