## Add Objects

[](#add-objects)

Choose one or more files (3MF/STEP/STL/SVG/OBJ/AMF) to import into the current project as [Object Sets](https://github.com/OrcaSlicer/OrcaSlicer/wiki/prepare_object_set).

Tip

See [Import and Export](https://github.com/OrcaSlicer/OrcaSlicer/wiki/import_export#import-model) for more information about supported file formats and import methods.

## Add Plate

[](#add-plate)

Adds a new print plate to the current project.

## Measure Tool

[](#measure-tool)

Use the Measure Tool to measure distances between points/edges/faces on your 3D model.
